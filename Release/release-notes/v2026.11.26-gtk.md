## Highlights

- **Vrecord 2026-11-26 with the GTK interface**, the classic Vrecord window, for Windows, macOS and Linux. It follows upstream vrecord and its date versions. The Windows Qt6 GUI has its own releases ([`v1.0.0`](https://github.com/harrypm/vrecord/releases/tag/v1.0.0)).
- **Test signal on Video Preview.** The test pattern and tone controls moved from the old Output tab to the output side of Video Preview, next to *Relay live feed*.
- **Same layout everywhere.** The Video Preview tab matches the Linux / macOS layout and fills the window, instead of sitting off to one side.
- **Linux**: `timecodexml2webvtt` is bundled with the other tools.

## Bug Fixes

- Fix the Windows device lists: Vrecord always uses the dialog program shipped next to it. A cached path to an older package's dialog had shown a bash error in *Relay output device* and pushed the page far wider than the window.
- Fix the Windows package carrying the Qt6 GUI: it now holds only the GTK interface. The Qt6 GUI and 23 Qt-only libraries are in the Qt6 releases.

> [!NOTE]
> **Windows**: unzip and run `Vrecord.exe`. It needs Blackmagic Desktop Video, plus Git for Windows or MSYS2 (`C:\msys64`).
> **Debian / Ubuntu**: `sudo apt install ./vrecord-gtk_2026-11-26_linux_amd64.deb`. **AppImage**: `chmod +x`, then run.
> **macOS Intel**: there is no Intel `.dmg` this time (the build machine could not eject the disk image). Use the `.app.zip` or the universal `.dmg`.
> Homebrew users on macOS and Linux can also install from the AMIA Open Source tap; see the [installation guide](https://github.com/harrypm/vrecord/blob/main/Resources/Documentation/installation_and_setup.md).

> [!WARNING]
> Not code-signed. On macOS, the first time, right-click the app and choose *Open*. gtkdialog, MKVToolNix and dvrescue have no arm64 builds: the arm64 and universal packages run their x86_64 versions under Rosetta 2.

## What's Changed

* The test signal controls are on Video Preview (the Output tab is gone).
* On Windows, the bundled dialog program is used before any cached path.
* Packages are named `vrecord-gtk_<version>_<platform>_<arch>`. Each release has its own `SHA256SUMS.txt`.
* The GTK interface is released separately from the Qt6 GUI and follows upstream vrecord's date versions.
