vrecord **2026-11-25** is the first full release of the Windows port: a new native **Qt6** front end for Windows, plus the GTK interface and the `vrecord` capture script on Windows, Linux and macOS.

## Highlights

- **Qt6 GUI for Windows**: live input preview, file playout to the DeckLink output, and level meters, all on one Video Preview tab, which is the tab the window opens on.
- **Capture follows the source**: the resolution / standard and the aspect ratio follow input changes automatically. An *Enforce manual selection* tick locks either one, and PAL widescreen signalling (WSS) sets 16:9 for anamorphic sources.
- **More audio options**: Opus recording (MKV / MP4), 16- or 24-bit PCM and FLAC, and 2 / 4 / 8 / 16 capture channels.
- **Test signal generator**: SMPTE, EBU, RP 219 and BT.2111 HDR bars with tone to the output, for checking a signal chain without a source.
- **Installer and updates**: a per-user Windows installer (no admin rights) or a portable zip. Both can update themselves, and every download is checked against [`SHA256SUMS.txt`](@DL@/SHA256SUMS.txt).
- **One package for every platform**: Windows, Linux (`.deb`, AppImage) and macOS (x86_64, Apple silicon, universal), each built and tested by CI.

## What's new

### Qt6 GUI (Windows)
- **Video Preview tab**:
  - Input preview at the native frame rate, beside the output device feed.
  - Stereo-pair level meters for input and output, with a choice of which pair is monitored.
  - Relay the live input to the output, or play a file to it. File playout is frame-exact: play / pause holds the exact frame, steps of 1 or 100 frames, a scrub bar, and a live-editable `HH:MM:SS:FF` counter. Type over it, or scroll / Up / Down on any part, and the output seeks.
  - The output standard can be set separately from the input standard, or left to match the file.
- **Device lists from the card**: input and output connector lists come from the card's hardware, as reported by the Blackmagic SDK.
- **Deck control**: RS-422 deck control with a timecode scan, and icon-only transport buttons.
- **Installed components**: a check that tools are present (ffmpeg-ma, MediaInfo, DVRescue, mpv and more), with their versions.
- **Drag and drop**: drop folders or files anywhere in the window. Mismatched drops are refused.
- **Settings**: saved atomically, with a backup copy.
- **Built-in self-test**: `VrecordQt6.exe --self-test`, run in CI on every build.

### Capture
- **Input following**: the standard and aspect follow the source; *Enforce manual selection* (one for each) turns this off.
- **PAL WSS**: 16:9 anamorphic is detected from line 23, and every other WSS group selects 4:3.
- **Capture channels**: 2 / 4 / 8 / 16. With 2 channels, the mappings that need channels 3 & 4 are disabled.
- **Opus**: recorded at 192 kb/s, in MKV and MP4 only. It uses libopus (included in the Windows build), or ffmpeg's built-in encoder where libopus is missing.
- **Bit depth**: 16 or 24 bit for PCM and FLAC.

### GTK interface
- **Test signal**: the controls are now on the Video Preview tab; there is no separate Output tab.
- **Layout**: the Video Preview tab uses the same layout as the Linux / macOS version.
- **Windows**: the package always uses its own dialog program, so a leftover older install can no longer break the device lists.

### Packaging
- **One file name scheme**: `vrecord_<version>_<platform>_<arch>[_kind].<ext>`, with a `SHA256SUMS.txt` covering every file.
- **Updates (Windows)**: off, notify (the default), or download and install when vrecord closes, set in **Config → Updates**.
  - Only published releases are offered; pre-releases never are.
  - Nothing is installed while a recording is running.

## Known limitations
- **Not code-signed.**
  - Windows SmartScreen may warn on first run: choose *More info → Run anyway*.
  - On macOS, the first time, right-click the app and choose *Open*.
- **Intel-only helper tools on Apple silicon**: gtkdialog, MKVToolNix and dvrescue have no arm64 builds, so the arm64 and universal macOS packages include their x86_64 versions, which run under Rosetta 2.
- **WSS not yet tried on real hardware**: aspect detection has been tested against synthetic WSS lines, not yet a widescreen PAL capture. Reports are welcome.

## Verify a download

```
sha256sum -c SHA256SUMS.txt --ignore-missing
```
On Windows, compare the output of `certutil -hashfile <file> SHA256` with the matching line in [`SHA256SUMS.txt`](@DL@/SHA256SUMS.txt).
