## Highlights

- **Vrecord 1.0.0, the Qt6 GUI on Windows, macOS and Linux**: the Qt6 GUI gets its own version numbers and releases. The GTK interface follows upstream vrecord in its own releases ([`v2026.11.26-gtk`](https://github.com/harrypm/vrecord/releases/tag/v2026.11.26-gtk)).
- **One name, Vrecord.** The program is `Vrecord.exe`. The window, the installer, the Start Menu and Apps & features all say Vrecord.
- **Video Preview first.** Live input preview, file playout to the card, level meters and the test signal generator are on one tab, which the window opens on.
- **Live-editable timecode.** Type over the playout counter, or scroll over any part of it, and the output seeks straight away.
- **A leaner package.** gtkdialog, the GTK launcher and 27 GTK-only libraries are no longer included.
- **Updates.** The updater offers only published Qt6 releases (`v1.0.0` and later) and checks every download against `SHA256SUMS.txt`.

## What's Changed

* The Qt6 GUI builds and runs on macOS and Linux as well as Windows. Each platform's build runs the Qt6 self-test in CI.
* The window fits a 13" MacBook screen: tab pages scroll when the window is smaller than they need.
* The Qt6 app is `Vrecord.exe` (Windows) / *Vrecord* (macOS), with "Vrecord" as its name everywhere.
* The Qt6 and GTK interfaces ship as separate packages and separate releases.
* The Qt6 GUI has its own version (`qt6/VERSION`). The updater reads the release list and skips GTK releases, drafts and pre-releases.
* Video Preview is the first tab. The playout counter is a single live-editable timecode; the frame field and the state badge are gone.
* Removed the *Open Legacy UI* button.
* `Vrecord.exe --screenshots <folder>` saves one image per tab without opening a window.
* Not code-signed: Windows SmartScreen may warn on first run. Choose *More info → Run anyway*.
